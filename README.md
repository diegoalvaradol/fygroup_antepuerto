# Sistema SSL | Antepuerto Panul

Sistema web para la gestión del **Antepuerto Panul**, enfocado en el **control de ingreso de camiones** y en la generación de **reportes operacionales del sistema logístico**.

La plataforma centraliza información relevante de la operación del antepuerto, permitiendo registrar movimientos, monitorear la actividad y obtener reportes para apoyar la gestión y toma de decisiones.

## Funcionalidades

- Control y registro de **ingreso de camiones**
- Reportes de **turnos**
- Reportes de **naves**
- Reportes de **thermos**
- Reportes de **contenedores**
- **Dashboard** con indicadores de operación
- Panel administrativo para la gestión de información

## Interfaz

La interfaz está basada en el template administrativo **SB Admin 2**, construido sobre **Bootstrap**, lo que permite una visualización clara y responsiva del sistema.

- Template: https://startbootstrap.com/theme/sb-admin-2/
- Framework UI: https://getbootstrap.com/

## Tecnologías utilizadas

- PHP  
- JavaScript  
- Bootstrap  
- jQuery  
- PHPMyAdmin  

## Objetivo

Centralizar y administrar la información operativa del **Antepuerto Panul**, permitiendo controlar el acceso de camiones y generar reportes de la operación logística del sistema.
